# Команда для проверок

- **go version** - команда для проверки какой версии Golang: go version go1.27.1 darwin/arm64
- **go env** - команда которая выводит информацию о текущей среде окружения компилятора
- **go mod init example/test** - команда которая создает модуль go.mod
